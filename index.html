Projects

Drift Detection in RAG Pipelines

This is a monitoring framework built to detect silent knowledge drift in RAG systems. It combines statistical analysis, linear regression trend detection, and component-specific tracking (retrieval vs. generation) to provide early alerts for system performance degradation.

CamSync

This is a web-based file management system that uses modern cryptographic techniques to encrypt users' files on upload & decrypt on demand access for authorized downloads. built using Flask, Nginx, and PyTorch-based transformers. It also features AI summarizer for encrypted files using PyTorch (DistilBERT), entropy filtering, and fallback logic with no external dependencies.
